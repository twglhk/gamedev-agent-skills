# TFT traits, every set (index for synergy design)

Every trait from Teamfight Tactics Set 1 (2019) to Set 18 Enchanted Wilds (2026): 18 sets and 7 mid-sets, 25 tables. Kept whole so a synergy slot in your own auto-battler or deckbuilder can pull from any of them. Each row: name, type (origin / class / unique), breakpoints, effect in one line with top-tier numbers.

**How to use.** When a synergy slot needs a new kind, scan the families below first, then the set tables for numbers. Copy the mechanic and the shape of the tiers, not the numbers; tune yours with your own auto-play probe. Before proposing, check the new kind against every live synergy in your game that raises the same stat; two synergies that raise the same stat read as one.

**Caveats.** Numbers are mostly from the League of Legends wiki set pages, which can show a later patch than launch; each set's header line says where it differs. Rows marked "(numbers unverified)" have the mechanic only. Mid-set tables (3.5, 4.5, 5.5, 6.5, 7.5, 8.5, 9.5) list only added and reworked traits.

## Families: which kinds exist, with examples

| Family | What it does | Examples (set) |
|---|---|---|
| Flat stat | holders or team gain one stat | Bruiser (6, 13), Vanguard armor (3, 4), Mystic MR (many), Arcanist AP (6) |
| Shield | shield at start or below a health line | Vanguard (14, 18), Rebel (3), Protector (3) |
| Mana | start mana, mana per hit, mana every few seconds | Invoker (5.5, 9), Star Guardian (3), Scholar (6) |
| Crit | crit chance and damage, abilities can crit | Assassin (4, 6), Ambusher (13), Executioner (14) |
| Stacking ramp | gains per attack or over time | Duelist (4, 7), Rapidfire (14, 18), Chrono (3) |
| Enemy shred | lower enemy armor, MR, attack | Caustic (18), Dazzler (4), Desert (2) |
| Distance and placement | damage by hexes to target, rows, adjacency | Sniper (3, 6, 9, 13), Longshot (16), Rebel adjacency (3), Form Swapper rows (13) |
| Economy | gold or loot on win or kill, shop upgrades | Space Pirate (3), Fortune (4, 11), Mercenary (6), Golden Ox (14) |
| Death and comeback | triggers when an ally dies or the team drops | Light (2), Dark Star (3), Cultist (4), Rebel smoke (13), Eldritch (12) |
| Area and extra hits | every Nth attack splashes, bounces, extra attacks | Cannoneer (5.5, 7), Blaster (3), Blademaster (1, 3), Sharpshooter (4) |
| Control | stun, knock-up, freeze on hit or cast | Glacial (1, 2), Demolitionist (3), Enforcer (6) |
| Summon | adds a unit that grows with the trait | Innovator (6), Cultist (4), Elderwood plants (18) |
| Capstone | emblem-gated top tier, near auto-win | Elderwood 9 (4), Star Guardian 10 (15) |
